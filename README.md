# GALAKTIKA — landing

Готовый статический лендинг без сборщика: `index.html`, `style.css`, `script.js`.

## Что уже подключено
- адаптивная мобильная/десктопная версия;
- шрифтовая связка `PP Neue Machina` + `Jost`;
- CTA ведут в указанную Яндекс Форму;
- FAQ;
- блоки «О нас», направления, видео, галерея, контакты;
- телефон и ссылки на Instagram / VK / Telegram;
- тёмная визуальная концепция с лаймовым акцентом.

## Что нужно сделать перед публикацией
1. Скачать из Яндекс Диска реальные фото/видео.
2. Заменить блоки `.image-placeholder` на изображения.
3. Положить `PPNeueMachina-Regular.woff2` в `assets/`, если есть лицензированный файл шрифта.
4. Для видео можно вставить `<video controls>` или iframe YouTube/VK.
5. Загрузить папку на хостинг (Vercel, Netlify, GitHub Pages или обычный хостинг).
